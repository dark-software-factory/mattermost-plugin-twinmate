# Legacy design materials

The pre-reset implementation was deliberately deleted on 2026-11-06 **without a code archive**. Prior documents under `docs/superpowers/`, the copied legacy specs here, and previous changes under `openspec/changes/archive/` describe a different prototype and **must not be treated as current requirements or completed features**.

They may inform research and help avoid repeating mistakes, but new behavior needs independent research, a fresh design decision and an approved OpenSpec change.
